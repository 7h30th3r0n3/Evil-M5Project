Amiibo dumps  (this folder is  evil/nfc/amiibo/  on the card)
=============================================================

Put your amiibo dumps here, then open  Cap NFC -> Amiibo -> Emulate.

Accepted files:
  *.nfc   Flipper / UberGuidoZ NTAG215 dump
  *.bin   raw 540-byte NTAG215 dump

The device emulates the NTAG215 (UID from the dump). No Nintendo keys needed.
Only use dumps of amiibo you own.
