Cap NFC - optional key / password dictionaries  (this folder is  evil/nfc/)
===========================================================================

All optional - the device tries built-in defaults first, then these if present:

  slix_pwd.txt       ISO15693 SLIX passwords, one per line (hex)
  desfire_keys.txt   DESFire keys to try, one per line (hex)
  amiibo/            your amiibo dumps (see amiibo/README.txt)

'#' starts a comment. Use only on tags you own or are authorized to test.
